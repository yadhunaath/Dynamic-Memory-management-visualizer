How It Works

Dynamic memory management divides available RAM into blocks. When a process requests memory, the OS chooses a hole using one of these strategies:

  • First Fit: Chooses the first free block large enough for the process.
  • Best Fit: Chooses the smallest free block that fits the process.
  • Worst Fit: Chooses the largest free block, leaving a bigger leftover hole.

When a process finishes, its block is freed and adjacent free blocks are merged to reduce fragmentation.
