HOW PAGING WORKS

Memory is divided into fixed-size frames. Process is divided into equal-size pages. A page table maps pages to frames, eliminating external fragmentation.

HOW SEGMENTATION WORKS

Process is divided into logical segments (Code, Data, Stack…) of variable sizes. Each has a base address and limit. No internal fragmentation, but external fragmentation can occur.
